# naeyuk — WORKNIUM 적산 (웹 프로토타입)

건설 적산 프로그램의 웹 클릭 프로토타입입니다. 표준 내역서·원가계산서 양식을 따르고, 모든 문서를 하나의 계산 엔진으로 계산합니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # 계산 엔진 테스트
npm run build    # dist/ 에 정적 파일
npm run build:single   # dist/single.html — JS·CSS를 넣은 한 파일 (웹에 바로 올리는 용도)
```

처음 쓰는 분은 앱의 **도움말 → 테스트 순서** (`/guide`)부터 보세요.

입력한 내용은 브라우저(localStorage)에 저장됩니다. 처음 상태로 돌리려면 **파일 → 예시 데이터로 되돌리기**를 누르세요.

## 화면

| 경로 | 화면 |
|---|---|
| `/` | 공사 목록 |
| `/project` | 프로젝트 홈 — 내역서 체계(설계 → 착공 → 차수·기성·설계변경·하도급 → 준공), 준공 조건 |
| `/estimate` | 설계/착공 내역서 — L 레벨, 접기/펼치기, 오른쪽 클릭 팝업메뉴, 칸 더블클릭 수정, 낙찰률 |
| `/cost` | 원가계산서 (1~18, A~L) — 문서별, 요율 수정 |
| `/phase` | 차수별 내역서 — 수량 분개, 비율분개, 공종 통째, 미배정 검사 |
| `/progress` | 기성내역서 — 회차, 전회/금회/누계, 확정. `?host=1` 은 통합 모드 |
| `/sub` | 하도급내역서 — 공종 선택 → 단가 × 하도급율 → 원가 항목 체크 → 이윤에서 단수조정 |
| `/sub/compare` | 원·하도급 대비내역서 — 도급 / 하도급대상 / 하도급 + 대비 원가계산서 |
| `/change` | 설계변경 내역서 — 당초 · 변경 · 증감, 신규 항목(설계 단가 × 낙찰률), 확정 |
| `/guide` | 테스트 순서 |
| `/unit` `/calc` `/machine` `/material` `/labor` | 일위대가 · 단가산출 · 기계경비 · 자재단가 · 노임단가 — 고치면 내역서·원가까지 다시 계산 |
| `/m` `/m/estimate` `/m/cost` | 모바일 조회 |

팝업: 표준품셈 검색, 표준시장단가 검색, 참고 내역서(별도 창) → 연결 데이터(일위대가·단가산출·노임·자재) 함께 가져오기.

## 구조

```
src/engine     계산 엔진 (순수 함수, 화면과 분리)
  estimate.ts  내역 합계 · 낙찰률/하도급율 적용 · 트리 편집
  cost.ts      원가계산서 · 비목 끄기 · 목표 공급가액(이윤 정산)
  subcontract.ts  하도급대상 · 하도급 · 원도급사 부담 비목
  phase.ts     차수 분개    progress.ts  기성    change.ts  설계변경
  basis.ts     근거 연동: 노임·자재·단산 → 일위대가 호표 → 설계 단가
src/data       예시 데이터 (용암교 보수공사, 참고 공사, 일위대가 등)
src/screens    화면
src/ui         공통 틀 (제목줄 · 주메뉴 · 기능버튼 · 작업화면 탭 · 창)
```

계산 규칙: 비목별 금액은 수량 × 단가 원 미만 버림, 합계는 비목 금액의 합. 원가계산서 각 비목도 원 미만 버림.

근거 연동: 설계내역서 단가 = 일위대가 호표(노임·자재·하위 호표·단산·% 줄로 계산), 착공 = 설계 × 낙찰률 88.479%. 이 규칙으로 용암교 xls의 착공 순공사비(163,747,465)와 18개 호표 합계가 그대로 나옵니다 (`npm test`).

아직 고정값인 것: 단가산출(단산) 안의 수식, 기계경비. 단산은 제목 줄 단가를 고치면 연결된 호표·내역서로 반영됩니다.
